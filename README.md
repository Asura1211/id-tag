# ID-Tag 2.0 演示 PWA

船舶缆绳管理交互原型。界面使用模拟数据，操作在刷新后重置，不连接真实 NFC、账户和服务器。项目保留原始案例证书供演示，仓库保持私有，分享前需核对素材授权及个人信息。

## 本地运行

在项目目录执行 `python3 -m http.server 8766 --bind 127.0.0.1`，打开 http://127.0.0.1:8766/。浏览器访问过一次后可离线打开。`index.html` 是页面，`css/app.css` 是样式，`js/app.js` 是原有交互和示例数据，`js/update.js` 与 `sw.js` 负责更新和离线缓存。现阶段原业务脚本暂未细拆，以保持行为一致。

## 维护和上线

先读 [AI 开发约定](AGENTS.md) 和 [部署说明](docs/deployment.md)。推送到 main 会在检查通过后自动发布到 https://nfc.hitlcj.top/。页面内提示发现新版本后，点击更新会刷新，演示数据会重置。
